📌 Project Overview

Bu proje, Türkiye’deki tarihsel deprem verileri üzerinde kapsamlı veri analizi, zaman serisi modelleme ve makine öğrenmesi uygulamaları içermektedir. Amaç; deprem dağılımını analiz etmek, büyüklük tahmini yapmak ve anomalileri tespit etmektir.

📊 Data Preprocessing

Tarih ve saat sütunlarının birleştirilmesi

Eksik ve hatalı verilerin temizlenmesi

Gerekli değişkenlerin seçilmesi

Günlük deprem sayısının oluşturulması

📈 Exploratory Data Analysis

Deprem büyüklüğü ve derinlik dağılımı

Günlük deprem sayısının zaman serisi görselleştirmesi

Coğrafi dağılım analizi

⏳ Time Series Modeling

ARIMA modeli ile günlük deprem sayısı tahmini

SARIMA modeli ile mevsimsel etkilerin modellenmesi

Model performans değerlendirmesi

🤖 Predictive Modeling

Random Forest ve Linear Regression ile deprem büyüklüğü tahmini

RMSE ve R² metrikleri ile performans analizi

🚨 Anomaly Detection

Autoencoder modeli ile olağandışı deprem örüntülerinin tespiti

🌍 Geospatial Visualization

Folium ve GeoPandas ile deprem lokasyonlarının harita üzerinde görselleştirilmesi

🛠 Technologies Used

Python, Pandas, NumPy, Scikit-Learn, TensorFlow/Keras, Matplotlib, Seaborn, Folium, GeoPandas
